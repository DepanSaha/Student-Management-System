# Student-Management-System
A Java-based application that provides a platform to manage student data. This system allows users to perform various operations like adding new students, viewing existing records, updating student details, and deleting entries, all through an intuitive graphical user interface (GUI).
Note: Table Schemas are provided seperately.
## Features
1. User Authentication
1. Student Management
2. Professor Management
3. Grade assignment and editing
4. View student details and grades
5. Print functionality for student information and grades
## Technologies Used
- Language : Java
- Backend : MySQL
- Framework : Swing
## Setup
1. Ensure you have Java and MySQL installed on your system
1. Set up the MySQL database with the required tables (USER, STUDENT_MASTER, PROFESSOR_MASTER, PROFESSOR_DEGREE, STUDENT_GRADE)
1. Update the database connection details in the relevant Java files
1. Compile and run the `LoginMain.java` file to start the application
## Usage
Log in with your credentials (Admin, Professor, or Student)
Navigate through the menu options to perform various tasks based on your role
Admin can manage both students and professors
Professors can assign and edit grades, and view student information
Students can view their personal details and grades
